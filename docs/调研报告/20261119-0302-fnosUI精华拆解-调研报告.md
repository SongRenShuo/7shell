# fnOS 1.1.23 UI 精华拆解（子代理实证调研）

> 日期：2026-11-19。素材：`fnos-1.1.23-1627.iso`（挂载 F:）→ 根文件系统 `trimfs.tgz` → 主控台 Web UI `usr/trim/www/`（Vite 构建产物，React 18 + Semi Design + Tailwind）+ 影视中心完整原始源码 `var/local/trim-media/static/assets/main.*.js.map`（source map 内含 sourcesContent，导出 603 个项目源文件）。解包命令与素材留存说明见文末「附录：素材复得」。
> 方法：子代理只读分析（131 次工具调用）。CSS 为压缩产物，用 grep 提取 class/变量/时长；JS 压缩但字符串常量与组件名可读；`locales/zh-CN/*.json` 是功能全景钥匙。未执行素材内任何文件。
> 本文件是证据底稿（每条带出处路径），结论与吸收裁定见[《fnOS UI 精华吸收-调研报告》](20261119-0302-fnosUI精华吸收-调研报告.md)。

**总体判断**：fnOS 前端是"两套设计系统、一个桌面壳"：
1. 主控台/桌面/Docker/下载中心等 = **Semi Design（字节）** 深度定制（`--semi-color-*` 变量 + `--semi-brand-*` 蓝色品牌色）+ Tailwind 工具类；BEM 前缀 `trim-ui__*` / `trim-os__*` 为自研壳组件。
2. 影视中心 = **自研 "brand/container" 令牌系统**（`bg-container-brightest`、`text-secondary`、`rounded-size-sm`），组件库 `packages/ui` 30+ 组件全源码可读。
3. 桌面壳（dock/launchpad/窗口管理/壁纸/小部件）是纯手写 React + framer-motion + Tailwind 任意值类。

## A. 设计语言（Design Tokens）

### A1. 色板（证据：`extract/usr/trim/www/assets/index-d4oQY4oJ.css`，535KB 主样式）
- **品牌色**：`--semi-brand-5: 0,102,255`（**#0066FF** 纯正蓝），hover 用 `--semi-color-primary-hover`（light 下 blue-4 `#3388FF`）；品牌蓝 0-9 全阶。
- **中性灰（light）**：grey-0 `#F8F8F8`（页面底）、grey-1 `#F2F3F4`（bg-0 应用底）、grey-2 `#C2C3C4`、grey-5 `#5A5B5C`、grey-8 `#1B1D1F`、grey-9 `#0E0E0F`（文字最深）。dark 全反转（grey-0 `#0C0C0D` → grey-9 `#F8F8F8`）。
- **语义色**（light / dark）：
  - danger `#E60023` / `#ED3F53`
  - success `#009E61` / `#30B47F`
  - warning `#FFA100` / `#FFC043`
  - purple `#CB59FF`、cyan `#00BDDE`、amber `#E06C00`、pink `#EB1E51`
- 每个语义色都有 `-light-default/-light-hover/-light-active` 三态浅底（Tag/Banner/Toast 的"浅底深字"组合：`background:success-light-default; color:success`）。
- **明暗双主题**：`body[theme-mode=dark]` 属性切换；Docker 子应用入口 JS `document.body.setAttribute('theme-mode', localStorage.getItem('fnos-theme-mode'))`（见 `apps/docker/index.html`）。支持 `semi-always-light/dark` 局部锁主题（壁纸上的 UI 强制 light）。
- **桌面专属色**：`--semi-color-fndesktop-navbarBg` light=`rgba(134,164,179,.05)` / dark=`rgba(12,13,13,.6)`；navbarBorder light=`rgba(255,255,255,.05)` / dark=`rgba(255,255,255,.2)`。
- 透明度语言：`bg-white-10/white-20/white-40/white-50/white-80`（壁纸上的元素全部用白色透明度阶，不引入新色相）。

### A2. 字体
- 界面主栈：`PingFang SC, Lantinghei SC, Microsoft YaHei, HanHei SC, Helvetica Neue, Open Sans, Hiragino Sans GB, 微软雅黑, WenQuanYi Micro Hei, Arial, SimSun, sans-serif`（main CSS 86 处出现，无自定义英文字体）。
- `static/fonts/Montserrat/`（Regular/Medium/SemiBold woff2 自托管）在主控台 CSS 中**未发现引用**——疑似预置/许可页用，中文界面完全走系统字体栈。
- 字号体系：正文 14px/22px 行高（`.trim-ui__table--td` 等），辅助 12px，标题 16-18px semibold，Launchpad 图标名 14px bold。
- 图表小字有 9px 特例（桌面磁盘小部件 `font-['PingFang_SC'] text-[9px]`）。

### A3. 形状 / 层级 / 阴影
- 圆角：Semi `--semi-border-radius-medium: 6px`（控件）、表格 4px、输入框/按钮 6px、菜单 6px（media 端 `rounded-0.375rem`）；**窗口 16px（WINDOW_RADIUS）、窗口内容 12px（CONTENT_RADIUS）**；登录卡 32px；系统升级/修复弹窗 `!rounded-[40px]`；Empty 插画容器无圆角。层级越大越圆（iOS 风格）。
- 阴影（关键三枚）：
  - `--semi-shadow-app`（应用窗口）：`0 15px 20px rgba(shadow色,.08), 8px 8px 16px -6px rgba(3,3,3,.08), 1px 12px 42px -4px rgba(10,10,10,.08)` + 1px `--semi-color-border-modal`（grey-9 @6%）描边
  - `--semi-shadow-elevated`（Modal）：`0 10px 20px rgba(0,0,0,.08), 0 10px 40px rgba(0,0,0,.12)`
  - `--semi-shadow-dropdown`（菜单）：`0 12px 42px -4px rgba(20,23,26,.12), 0 8px 18px -6px rgba(20,23,26,.2)`
- **毛玻璃**：`backdrop-blur-[20px]`（dock、登录卡）+ `bg-white-10` 或 `--semi-color-fndesktop-navbarBg`；Launchpad 用 `backdrop-blur-2xl`（40px 级）。Semi 组件自身无毛玻璃，毛玻璃只出现在"桌面层"。
- 间距：Tailwind 自定义 spacing 语义名 `tight / super-tight / base-loose`（如 `py-base-loose`、`px-tight`）+ 常规 4px 网格；页面容器统一 `p-5`（20px）+ `gap-3`（12px）。

### A4. 动效
- Semi 时长档：`90ms / .12s / .18s`（fastest→fast），easing `easeIn cubic-bezier(.4,0,1,1)`、`easeOut cubic-bezier(0,0,.2,1)`、`easeInOut cubic-bezier(.4,0,.2,1)`。
- Launchpad：scale 1.1→1 + fade，**0.1s**（main JS `KQe` 组件）。
- 菜单弹出：framer-motion scale 0.5→1 spring **0.2s**（`packages/ui/src/Menu/Menu.tsx:147-155`）。
- 折叠面板：icon rotate 90° `.18s ease-in-out`，内容 height `.25s ease`（Docker CSS `trim-ui__collapse--*`）。
- 行淡出：`fadeOutLeft .4s forwards`（`trim-ui__FadeOutDisappear--fadeOutLeft`）。
- 加载 spinner：24px 环形 SVG，`spin-loading 1s linear infinite`，色值 `rgba(33,115,223,1)`（`apps/docker/index.html`）。
- Lottie 场景：文件任务进行中（dock 图标位）、系统升级/修复（升级弹窗，带 dark/light 与 fnos/fygo 品牌四变体 URL `/lottie/upgrade/{dark|light}/{fnos|fygo}/upgrading.json`）、首次配置引导。`static/lottie/`：anmt、formatting、formattingFinish、upgrade。
- 图表动画关闭（`isAnimationActive:!1`，实时数据场景 `Chart-DMKek9KK.js`）。

## B. 桌面形态（Desktop Shell）

证据主要来自 `extract/usr/trim/www/assets/index-Sd3kzNFy.js`（2.58MB 主入口）。

### B1. 布局骨架（`gat` 组件）
```
<div class="flex h-screen w-full relative">
  <壁纸层 eat/>
  <div class="h-screen fixed left-0 inset-y-0 z-[1]" style="width:66px"> dock </div>
  <div class="flex-1 z-0 desktop"> 桌面图标 + 小部件 + 窗口层 </div>
</div>
```
- Dock 总宽 **66px**（图标槽 47px 宽、h-10=40px 高、内图标 36px）。

### B2. Dock（左侧竖条，`Ust` 组件）
- 外层 `size-full py-4 pl-3.5`（与屏幕边缘留 16px/14px）。
- 主体：`rounded-md(6px) border rgba(255,255,255,0.20) bg-[var(--semi-color-fndesktop-navbarBg)] backdrop-blur-[20px]`，内部 `flex-col py-3`。
- 三段结构：
  1. **顶部固定**：「桌面」按钮（全部最小化/恢复 `minimizeAll/cancelMinimizeAll`）+「全部应用」按钮（Launchpad）；两按钮间及下方用 `border-b rgba(255,255,255,0.20)` 分隔。
  2. **中部 flex-1 可滚动**：已打开窗口图标列表（`gap-2`，竖排），点击激活窗口（`activateTask`），激活项 `border-l-[3px] border-focus-border` + `bg-white-10`。
  3. **底部固定**：文件任务（上传中显示 lottie 循环动画，`FileTaskInfo` 徽标计数）、通知（未读徽标）、我的账号（菜单：我的账号/个人设置/退出登录/关于/帮助中心/关机重启）、设置（仅 admin 显示）。
- 每个槽：hover `bg-white-10`，右侧 Tooltip（position right），激活左侧 3px 蓝条。

### B3. Launchpad（开始菜单，`KQe` 组件）
- 全屏覆盖层：`absolute inset-0 z-[1000001] bg-[rgba(0,0,0,0.70)] backdrop-blur-2xl`。
- 进出场：scale 1.1↔1 + opacity，0.1s（framer-motion）。
- 顶部搜索框：宽 380px、高 44px、`rounded-[8px] bg-white-10`、边框 white-20→聚焦 white-40、placeholder white-50、光标白色；**输入防抖 300ms** 过滤 app 名。
- App 网格：`grid-cols-[repeat(auto-fill,_172px)]` 居中；单元格：80px 图标区 + 14px bold 白字（`WQe`）。`hiddenDesktopIcon` 的应用只进 Launchpad 不上桌面。
- 内容区留白：`pl-[280px] pr-[216px] py-[64px]`（为 dock 与右侧小部件列让位）。

### B4. 桌面图标（`oD` 组件）
- 单元格 **130×124px**，flex-col 居中，`gap-4`；图标 **50×50**；名称 14px bold 白字，`line-clamp-1` max-w-112px，`title` 悬停全名。
- 名称文字阴影（壁纸可读性）：`textShadow:"0px 1px 6px rgba(0,0,0,.2), 0px 0px 4px rgba(0,0,0,.5)"`（`prt` 常量）。
- 布局：`flex flex-col flex-wrap place-content-start items-start py-base-loose` —— **先竖排后横向换列**（经典桌面流），桌面区 `pl-[66px]` 给 dock 让位。
- AppStore 图标右上角红点（有更新：`!w-3 !h-3 !top-[20px] !right-[45px]`）。

### B5. 桌面小部件（statusBar.widgets）
- 五种：system（运行状态：主机名/运行时长 天时分秒）、net（收发速率）、disk（存储读写）、storage（存储空间，进度条）、ups。
- 默认开启 `["system","net","disk","storage"]`（`Uet` 组件）；用户可配置，持久化到服务端 `browser.desktopWidget`（`usrd.get/set`）+ 前端缓存。
- 网速/CPU 点击直接打开资源管理器对应页（`openAppFromCommand(ResourceManager, performance, NET)`）——**小部件即入口**。
- 进度条颜色阈值：`<90% primary，90-95% warning，>95% danger`（`fJe` 组件），条高 6px 圆角 10px。
- 轮询 60s（UPS），且监听 `visibilitychange` 页面可见才刷新（省流）。

### B6. 窗口模型（`BLe` 组件 + 常量 iE）
- 常量（index-Sd3kzNFy.js 内）：`WINDOW_DEFAULT_WIDTH=1100`、`WINDOW_DEFAULT_HEIGHT=640`、`HEADER_HEIGHT=44`、`SIDEBAR_WIDTH=220`（应用内左侧导航）、`WINDOW_RADIUS=16`、`CONTENT_RADIUS=12`、`CONTENT_RIGHT_MARGIN=8`、`CONTENT_BOTTOM_MARGIN=8`；`getContentWidth = W-220-8`。
- 标题栏 44px：左侧 `trim-ui__app-layout--header-title`（pl-4 pr-9，14px，**双击最大化** `onDoubleClick`）；右侧按钮组（设置/最大化/关闭）。**关闭按钮 hover 变红**：`hover:!bg-[var(--semi-color-danger)] hover:!text-white`。
- 窗口本体：`trim-ui__app-layout--window` = `box-shadow: var(--semi-shadow-app); outline: 1px solid var(--semi-color-border-modal)`；拖动/缩放中加 `is-dragging/is-resizing` 类置 `will-change: top,left,width,height`。
- 拖拽手柄=标题栏，`layoutType==="window"` 才可缩放；窗口大小/位置按 **应用+用户** 持久化 localStorage `UserSettings-{uid}`，防抖 100ms（`Qet` 组件），支持记"原始尺寸"（最大化恢复）。
- 窗口状态机含 `minimized`；dock 图标列表即任务列表（`y6()` store）。
- 上传未完成时 `beforeunload` 拦截离开（`wrt` 组件，文案 `page.leaveConfirmation`）。

### B7. 壁纸系统（`eat` 组件 + `appcgi.sac.desktop.v1.*` API）
- 三类壁纸：`wallpaperType` 100=单图（singlePhotoWpId）、300=纯色（singleColorWpId）、500=动态（dynamicWpId）。
- 动态壁纸有**两层图**（dynamicUrl1 + dynamicUrl2）——交叉淡入淡出实现循环过渡；static/bg/live/ 下每张动态壁纸都有 `-light/-dark` 两版（wallpaper-1~5）。
- 填充模式 fillMode：0=cover、1=fill、2=contain（object-cover/object-fill/object-contain）。
- 纯色壁纸带**不透明度**（bgOpacity → alpha = round(opacity*2.55) 转 hex）。
- 主题（light/dark）与壁纸类型一起存服务端（desktopSetTheme/setWallpaperType/setFillMode/setBgColor/setWallpaper/removeWallpaper/**markWallpaper**（收藏壁纸）），前端 localStorage 缓存按 uid 键（`DesktopConfig-{uid}`）。
- 静态壁纸 6 张 webp（static/bg/wallpaper-1~6.webp）。

### B8. 登录 / 锁屏
- 登录页：全屏壁纸 wallpaper-1 背景，卡片 `rounded-[32px] bg-white-10 backdrop-blur-[20px]`（`login-form-CnYqdqWL.js` 的 `W` 组件）+ **渐变描边**（`login-form-DQaufl8Q.css` `.gradient-border:before`：1px padding + `linear-gradient(to bottom, rgba(255,255,255,.4), rgba(255,255,255,0))` + mask 挖空，顶部亮底部消失）。
- 输入框圆角 10px、透明边框、`-webkit-autofill` 动画 hack 防黄底；禁用主按钮保持品牌蓝底 `rgba(255,255,255,.4)` 文字。
- 无用户时重定向 `/system` 初始化向导；`semi-always-light` 锁亮色。
- 路由：`/oauth、/login、/reset-password、/signin、/system`（主控台路由表 `Eat`）。
- 关机/重启确认弹窗（`taskbar.power.*`）：重启「将中断进行中任务」、关机「需按电源键开机」，配破坏性二次确认。

### B9. 全局交互约定
- **原生 contextmenu 全局禁用**（除 input/textarea/select-text 元素外 preventDefault）；dragstart 同样按 select-text 类放行（`gat` 组件 useEffect）——为自绘菜单与自定义拖拽铺路。
- web 控制台**没有**桌面右键菜单/图标框选（只有文件管理器内部有）。

## C. 组件语言（packages/ui 源码，React 端）

### C1. 令牌系统（与 Semi 并行的第二套）
`packages/ui/src/Button/Button.tsx`：`bg-brand / bg-container(-dim/-dimmest/-bright/-brightest) / text-default/-secondary/-third/-disabled / text-success/-error/-warn/-accent / rounded-size-xs|sm|base` —— surface 五阶 + 品牌一色 + 语义四色。

- 尺寸：sm 28px / base 36px / lg 40px / xl 54px，图标按钮同高方形；字重 500；禁用 `opacity-50`；loading 时主按钮白色 spinner、warn 红色、次级 WeakenedLoading（弱化三点 loading，`Loading/WeakenedLoading`）。

### C2. 反馈组件
- **Message**（`Message/Message.tsx`）：`bg-container-brightest mt-6 py-3 px-4 shadow-lg border-1 border-default rounded-8px`，24px 语义色实心图标（CheckCircleFill 等）+ 16px 正文 + 可选关闭；info 用 accent 色。

- **Empty**（`Empty/Empty.tsx` + `Empty/assets/`）：5 种插画 **NoData/LoadFailed/NoFile/NoHardDisk/NoSearchResult，每种 Dark/Light 双 SVG**；三档尺寸（图标 48/100/150px），标题 text-third、描述 text-disabled。
- **DialogV2**（`DialogV2/src/components/`）：Root/Trigger/Content/Title/Footer/Close 组合式 API；Content 支持 `loading` —— 弹窗内叠 70% 白遮罩 + Loading（数据型弹窗标准态）；正文 `p-5 text-sm`。

### C3. 菜单/下拉（`Menu/Menu.tsx`、`Dropdown/Dropdown.tsx`）
- 菜单：min-w-110px、py-1(4px)、1px border + rounded-6px、shadow；**分组数组之间 1px 分隔线**；选项 selected 高亮 + `autopilot` 自动滚动到选中项。
- 动效：scale 0.5→1 spring 0.2s（默认）/ height 0→auto linear 0.2s（slide）。
- Dropdown：trigger=click/hover/contextMenu；**contextMenu 用 portal 到 body + 鼠标坐标 + 视口越界翻转**（`checkBoundaries`）；hover 型 300ms 延迟关闭，鼠标在菜单上不关（可滚动）；**滚轮滚动页面时自动关闭**；子菜单位置 left-105%。

### C4. 其他
- **Scrollbar**（`Scrollbar/Scrollbar.tsx`）：`mac-scrollbar` 库封装，track/thumb 各 **4px**、track 透明、minThumbSize 40、`trackCentered`（-mr-3.5 pr-3.5 内容居中补偿）、invisible 可分别隐藏横向/纵向、smooth 平滑滚动。

- **Table**（fn-ui/trim-ui，Docker 端 CSS）：`--semi-color-table-HoverBg` hover、`-ActiveBg` 选中、斑马纹 `--stripe-color` 变量、sticky 表头、**列间 1px×16px 竖向分隔线（th:after）**、单元格 8px padding 14px/22px 字号、表格整体 4px 圆角、可调列宽 `--resizer`。
- **PickFolderDialog**（`packages/ui/src/PickFolderDialog/`，含 hooks/labels 子树）：NAS 场景的"选择存储空间→文件夹"两级选择弹窗，全系统复用（Docker 建容器、下载中心、备份均用）。
- **Breadcrumb**（`Breadcrumb/` + `DirectoryPath`）：选中段 `bg-[var(--semi-color-primary-light-default)]` 高亮、文件夹名 138px 截断 14px 字（path-BvDw_EGR.js）。
- **FadeOutDisappear**：fadeOutLeft 0.4s 行级消失动画（列表删除反馈）。

### C5. Semi Design 关系

## D. 交互精华

1. **右键菜单三级结构**（文件管理器，locales/zh-CN/apps/file-manager.json `action.*`）：
   - 文件：打开/打开方式/新窗口打开/下载/复制/剪切/粘贴/重命名/删除/压缩/解压/收藏/详细信息/分享（共享给设备用户）/分享外部链接/复制链接/编辑分享

28. 后端错误码全量映射用户文案，绝不裸透传 —— E；**适合**（7shell SSH 错误同理）。
29. 应用崩溃页：明暗插画 + 重试按钮 —— D11；**适合**。
30. 页面可见才轮询（visibilitychange）—— B5；**适合**（SSH 监控面板）。

**Docker UI（对标 ContainerPane）**
31. 左侧导航「概览/容器/Compose/镜像(带计数徽标)/仓库/网络」+ 服务未启用时只露概览 —— G2；**适合**。
32. 概览页 = 三行可点摘要（点击跳 tab）+ 实时 CPU/内存/网络迷你图 + 健康灯 —— G3；**适合**。
33. 容器 9 态机 + 浅底 tag 状态列 + 「更多」行菜单 —— G4；**适合**。
34. 「复制容器」默认不设启动状态（复制≠自启）—— G4；**适合**（低成本防事故）。
35. 创建容器向导：基本设置→高级设置（端口/存储/环境变量/网络/capabilities/命令/资源限制 CPU 权重高中低+内存上限）分区卡 —— G4；**适合**。
36. 更新镜像 5 步确认清单弹窗（停容器→数据风险→加速源→不可取消→失败补救）—— G5；**适合**（远超普通 confirm 的风险教育）。
37. 加速源拖拽排序表达优先级 —— G5；**适合**。
38. Compose：已有 yml 检测弹窗 + 运行时配置只读 + 「编辑需重新构建」常驻提示 —— G6；**适合**。
39. 网络删除护栏（关联容器数>0 禁止）+ CIDR/端口冲突专属报错 —— G7；**适合**。
40. 存储迁移双警告（服务不可用 + Docker 类应用先卸载）—— G8；**适合**。

**不适合照搬**
- Semi Design 全量引入（1MB JS+642KB CSS）：7shell 是 Vue+Tailwind，只取令牌与模式。
- 两套设计系统并存（Semi + brand/container）：维护成本高，7shell 应一套到底。
- 40px 超圆弹窗/32px 登录卡：偏 iOS 风，7shell 桌面工具语境建议 ≤16px。
- 全局禁用原生右键且桌面无右键菜单：NAS 场景简化了，7shell 文件管理反而需要完整右键菜单（参考 file-manager 的 action 结构实现）。
- PingFang SC 优先字体栈：Linux 客户端应以系统默认 UI 字体（或思源黑体）优先，避免 mac 字体查找开销。
- Montserrat 自托管却基本未用：字体资产冗余教训。
