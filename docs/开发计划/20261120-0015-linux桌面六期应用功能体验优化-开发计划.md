### F. 文件编辑器（重点增强，独立批次）

现状底细：`FileEditor.vue` 共 233 行，形态是**模态弹窗 + 纯 textarea**；头注自述「no syntax highlighting yet」；实测无行号/查找替换/撤销 UI/编码处理/Tab 处理/换行开关（grep 全 0）。扎实的部分：脏标记与未保存关闭护栏（ Escape 曾丢稿的教训在案）、防截断（读失败禁保存）、与窗口关闭的未保存联动（`files.setUnsaved`）。

| # | 痛点 | 证据 | 目标 | 批次 |
|---|---|---|---|---|
| F1 | 模态弹窗锁死：编辑器不能与文件列表并排、不能多文件同开、不能最小化 | 〔码〕DialogRoot + `w-[min(52rem,…)]`；多文件=弹窗摞弹窗 | 桌面内**编辑器窗口**（进桌面窗口系统，多文件=窗口内多标签，复用 A1 的标签基建）；应用级保持对话框（双模式） | 三 |
| F2 | 无行号/语法高亮/查找替换/撤销重做 UI | 〔码〕头注自述；textarea 一览无余 | **引入 CodeMirror 6**（行号/高亮/查找替换面板/内建 history/大文件虚拟滚动），语言按需注册（json/yaml/shell/conf/log） | 三 |
| F3 | 保存无冲突保护：读后远端被改，保存=静默覆盖 | 〔码〕save 直接 writeText，无 mtime 比对；目录列表已有 mtime 数据 | 读时记 mtime → 保存时引擎比对，不匹配 → 冲突三选（覆盖/另存副本/重读合并） | 三 |
| F4 | 无编码处理：utf-8 之外（GBK 日志常见）直接乱码或被拒 | 〔码〕read_text/write_text 无编码参数 | 二进制探测拒绝保持；编码切换（GBK/UTF-8）**后置**（需 encoding_rs，Rust 依赖高门槛单评审） | 三（基础）/ 后置 |
| F5 | Ctrl+S/Ctrl+F 不生效、无字号/换行开关、无只读预览态 | 〔码〕无 keydown 处理 | 编辑器快捷键集（Ctrl+S 保存/Ctrl+F 查找）+ 设置小节（字号/换行/空格显示）+ 大文件只读预览模式 | 三 |
| F6 | 未保存状态只有弹窗内可见 | 〔码〕files.setUnsaved 只护关闭 | 未保存标签在窗口标题与通知中心可见（复用 A1 通知源） | 三 |

**决策点 E1（推荐已裁定）**：引入 CodeMirror 6（npm 新运行时依赖，MIT，框架无关；替代自研行号/高亮/查找的数周成本）。**决策点 E2**：桌面=窗口化多标签、应用级=对话框，双模式延续 `ContainerPane` 先例。**决策点 E3**：编码切换后置单评审（encoding_rs 走 Rust 依赖高门槛）。

## 三、批次划分与车道

- **批次一（终端体验）**：车道 K（前端：窗口内标签条 + 搜索浮条 + 单实例裁定落地）——不触 Rust（复用 terminal.open）；涉及 `terminals.ts` 桌面分支、`WorkbenchPane`、新 `WorkbenchTerminalWindow` 标签条组件。真机：连开 3 个 shell 标签仅 1 条连接佐证 + 搜索高亮。
- **批次二（文件管理器）**：车道 L（前端，共享组件加法）：双视图/多选/详情抽屉/收藏最近/排序记忆。真机：建删改收全链路 + 应用级文件 tab 走查（可见变化列表）。
- **批次三（文件编辑器）**：车道 Q（Rust：read/write_text 信封带 mtime + 二进制探测保持；编码切换后置单评审）+ 车道 L2（前端：CodeMirror 6 编辑器窗口——桌面多标签/应用级对话框双模式、查找替换面板、行号/高亮按需语言、Ctrl+S/F、只读预览、未保存外显）。真机：冲突三选实测、大文件护栏、多标签。
- **批次四（回收站/传输/批量/通知源）**：车道 M（前端 + 少量命令复用）：C1-C4 + A3 终端-文件联动。真机：多选恢复、失败汇总、历史回放。
- **批次五（系统面板/监控）**：车道 N（前端为主；journal 过滤若需参数化走既有 journal 命令的行过滤，前端实现即可）：D1-D6（D5 面板 Semi 化、D6 统计图表为新增大项）。真机：过滤读数 + 图表采样读数。
- **批次六（桌面全局层）**：车道 P（前端）：E1-E4。真机：右键菜单、框选、帮助层。
- **批次七（收口）**：门禁/真机总走查/NSIS/文档回填。

每批：冲突→独立工作树；决策点按推荐并记录；定向测试先行；真机只读 + 自建资源。

## 五、风险

1. **A1 终端标签化**触及 `terminals.ts`（全应用 tab 总仓）——只许在桌面分支内改；应用级标签条行为零变化（既有 20 例 spec 不改）。
2. **B2/B3 桌面多选与详情**改动 FileBrowser 较深——加法式：新交互挂新 data 结构，旧单选路径保留；应用级走查列清单。
3. **排序/视图/收藏记忆**落 localStorage，键名带 session 维度，防串味（LESSONS I15）。
4. **journal 前端过滤**对大日志的内存预算——行数上限沿用既有 500 行纪律。
5. 形态评审：批次二双视图/详情抽屉先出预览图（I26）。
6. **CodeMirror 6 是首个新增前端运行时依赖**：体积约 350KB gzip（按需语言包），走 CONTRIBUTING 依赖评审 + 形态评审双门；若否，回退自研行号+查找（成本另计）。
7. **read/write_text 信封带 mtime 是契约变更**：旧宿主无该字段——按 A1/A2 纪律镜像可选性，旧形状夹具回归。
