## 一、目标形态

workbench 标签页从「一张带图标的页面」变成一个**完整的桌面外壳**：顶部状态栏、桌面图标网格、
全屏应用启动器、可拖动/缩放/最大化/最小化的浮动窗口、底部悬浮任务栏。打开终端、文件、监控、
系统面板、回收站，不再是跳到顶部标签条，而是在桌面上开窗。

应用整体仍是标签式（7shell 的既有契约），但 workbench 会话内的一切都发生在桌面上。

### 2.2 动效与手势

- 打开窗口：从默认居中位置出现，`transition: transform 0.2s`。
- 关闭：`transform: scaleY(0)`，200ms 后从集合移除。
- 最小化：`transform: scale(0)`；从任务栏再点恢复。
- 最大化/还原：`transition: all 0.3s`；最大化时铺满状态栏以下、任务栏以上，圆角归零。
- 拖动：按住标题栏（或标题栏左侧非图标区）移动；拖到 `top ≤ 23px` 自动最大化；松开结束。
- 缩放：CSS `resize: both`（右下角手柄），尺寸按应用记入 `localStorage`，下次打开恢复。
- 焦点：点击窗口任意处置顶；活动窗口描边（参考是 1px `#740a0a` 圆角 10px，本仓改为令牌化的 accent 描边）。
- 双击桌面图标打开；右键图标出菜单；点桌面空白关菜单/取消选中。
- 启动器打开时把工作区压到更低层（`z-index`）并蒙一层黑；点蒙层空白关闭。

### 2.3 视觉语言

- 所有桌面元素都在「图之上」，固定为白字 + 半透明深底，不跟随浅色主题（延续已落地的对比度修复）。
- 图标是彩色贴纸风（40-48px PNG/SVG），不是线性图标；本仓用 lucide 时统一加彩色底片，保持"贴纸"观感。
- 玻璃感来自三处：窗口 blur 15px、任务栏 blur 5px、启动器瓦片 hover blur 15px。
- 圆角尺度：窗口 8、任务栏 12、菜单 5-7、图标格 7-9。

## 四、架构

### 4.1 新增

- `apps/desktop/src/lib/workbench/windows.ts`：纯逻辑。窗口记录（id、kind、tabId、标题、图标、
  位置/尺寸、`min/max/focused`、z 序号）、`open/close/focus/minimize/maximize/restore/move/resize`、
  尺寸持久化（按 kind 或 tab 标题的稳定键），以及「关闭窗口 = 关闭它承载的 tab」的收口。
- `apps/desktop/src/components/workspace/WorkbenchWindow.vue`：窗口铬（标题栏、三键、手势、
  动画 class），内容用默认插槽。
- `apps/desktop/src/components/workspace/WorkbenchStarter.vue`：启动器蒙层与图标格。
- `apps/desktop/src/components/workspace/WorkbenchStatusBar.vue`：顶部 23px 状态栏。
- `apps/desktop/src/components/workspace/TabBody.vue`：从 `WorkspaceTabs.vue` 抽出的单标签内容
  （terminal / files / inspect / workbench / welcome），带 `:tab`、`:active`，由顶部标签与桌面窗口共用。

### 4.2 改动

- `WorkbenchPane.vue`：重写模板为「状态栏 + 桌面（图标格/启动器/窗口层）+ 任务栏」，保留壁纸、
  快捷方式、图标密度、拖拽排序、桌面设置、电源；图标双击改为开窗口而不是切顶部标签。
- `WorkspaceTabs.vue`：把每个 tab 的内容抽到 `TabBody.vue`；workbench 打开的 tab 标 `windowed`，
  顶部标签条不显示、内容由窗口渲染。
- `terminals` store：`openTerminalTab` 等接收 `windowed` 选项；关闭窗口时关闭对应 tab。
- i18n：状态栏、启动器、窗口动作（最小化/最大化/还原/关闭）、菜单分组标题，en + zh-CN。
- 样式：参考度量写进 workbench 的 scoped 样式与 `globals.css` 的少量令牌（玻璃、菜单 teal、
  桌面 chrome 白字），不引入 Less。

### 4.3 不变量

- 桌面元素不读主题前景色（对比度）；窗口内的应用内容仍用主题。
- 窗口不是新的连接：每个窗口的 tab 与今日的 tab 完全同构，policy / 审计 / 生命周期不变。
- 关闭窗口必须先关 tab（连接随之收口），不能留下不可见的连接。
- 键盘可达：窗口三键可 Tab 聚焦、Enter 触发；拖动不劫持点击；Esc 关启动器。

## 五、车道划分

- **车道 C（窗口系统）**：`lib/workbench/windows.ts` + `WorkbenchWindow.vue` + 单测；
  `TabBody.vue` 抽取 + `WorkspaceTabs.vue` 改为使用它（行为不变，现有 spec 全绿）。
- **车道 D（外壳铬）**：`WorkbenchStarter.vue`、`WorkbenchStatusBar.vue` + 单测；任务栏与图标格
  的展示组件（props/emits 约定见本节末），不动 `WorkbenchPane.vue`。
- **主控**：`WorkbenchPane.vue` 组装、`terminals` store 的 `windowed` 选项、i18n、真机验收、
  全量门禁、Windows 安装包。

约定（两条车道与主控之间的接口）：

```ts
// WorkbenchWindow.vue
props: { id: string; title: string; icon?: Component; state: "normal" | "min" | "max"; focused: boolean }
emits: { focus: []; close: []; minimize: []; maximize: []; restore: []; move: [{ left: number; top: number }]; resize: [{ width: number; height: number }] }

// WorkbenchStarter.vue
props: { open: boolean; apps: { id: string; label: string; icon: Component; tone: string }[] }
emits: { close: []; launch: [id: string] }

// WorkbenchStatusBar.vue
props: { host: string; user: string; clock: string; connected: boolean }
emits: { disconnect: [] }
```

## 七、风险与对策

- **xterm 在窗口内重挂载**：窗口只是同一 tab 的另一个宿主，`TerminalPane` 以 tab id 为 key；
  窗口最小化不卸载内容（`scale(0)` 而非 `v-if`），关闭才卸载。
- **标签条与窗口双份内容**：`windowed` tab 不进顶部条；`WorkspaceTabs` 只渲染非 windowed。
- **拖拽与图标拖拽排序冲突**：窗口拖动只从标题栏发起，图标格的手势不受影响。
- **尺寸恢复写坏 localStorage**：读写都过纯函数与夹取，越界值回默认。
- **移动端/窄窗**：窗口尺寸夹取到容器内，最大化铺满工作区；任务栏在窄窗下缩短外边距。

## 八、不做

- 不做参考里的「应用商店 / 自定义应用 / 内置浏览器 iframe 应用」——7shell 没有那个生态。
- 不做窗口自由缩放动画之外的物理惯性、吸附分屏、多桌面。
- 不复制参考的图标资源（它有版权的 PNG），用现有 lucide + 彩色底片。
