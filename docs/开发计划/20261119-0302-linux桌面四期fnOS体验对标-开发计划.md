## 一、生产级可用的定义（验收总闸）

1. **功能真实**：桌面上每一个可点击的入口背后都是已实现并真机验证过的能力；不允许 disabled 占位（本仓既有纪律）。
2. **门禁全绿**：`pnpm check`（15 步）+ `cargo fmt/clippy -D warnings/test --workspace` + `cargo deny`（advisory 走代理）。
3. **真机验收**：103.36.220.245（Docker 29.9.3，13 容器在线：oceanbase/tidb/mysql8/mssql/oracle-free/vastbase×2/opengauss——**只读验证，禁止 stop/rm 用户容器**；破坏性动作只对无状态测试容器验证，或仅验证确认弹窗弹出即取消）。
4. **安装包**：NSIS 产物带当批全部功能，哈希回填本文件对应批次小节。
5. **不变量不破**：安全模型（命令不上机、policy 门、审计）、`docs/LESSONS.md` 全部活跃规则、桌面特有红线（壁纸上的 chrome 白字不随主题；关窗必关 tab/连接；最小化不卸载内容；destructive 一律 policy+确认+审计）。
6. **吸收纪律**：只平移结构与参数，不引 Semi、不换品牌色、不做第二套设计系统；新增界面 en+zh-CN 双语（i18n 守卫）；表格走 `lib/table.ts` 契约；字号/选区守卫不破。
7. **影响面锁死（本四期最高边界，先于一切裁定）**：**只调整 Linux 桌面相关功能，不影响、不改动 7shell 其他既有功能**。
   - 允许触碰：`apps/desktop/src/components/workspace/`（桌面域组件与 spec）、`apps/desktop/src/lib/workbench/`、`components/ui/` 新增基础件（WbButton/WbTag/Empty 等新文件）、`styles/globals.css` 新增 `--workbench-*` 段（只增不改既有取值）、桌面专属 i18n 键、`src-tauri` 桌面命令（workbench/trash/process/system/container 的桌面路径）与 `sevenshell-core` 对应函数、desktop descriptors。
   - 不得改动：应用级既有功能的行为与外观——会话库/会话编辑器、终端工作区与标签条（windowed 分支除外）、文件浏览器面板、监控面板、BatchPanel/TransferPanel 本体、应用级容器 tab、主题 token 既有取值、CSP/安全模型、非桌面 descriptors。
   - **共享组件隔离条款**：`ContainerPane.vue` 等「桌面窗口与应用级 tab 共用」的组件，若需桌面专属呈现，一律以 props 双模式隔离（如 `layout="desktop" | "flat"`，应用级默认 flat＝现状原样），共享路径的行为与视觉变化视为违例；stores（terminals/files/container）只允许在桌面专属分支内改动，应用级分支零 diff。
   - 每批验收时复核：`git diff --stat` 中出现的共享文件逐个核对是否只含桌面分支改动；应用级相关 spec（WorkspaceTabs 非桌面分支、终端/文件/监控/批量面板 spec）只增不减、既有断言不改。

## 三、批次一：视觉地基（桌面 chrome token 化 + 语言移植）

### 3.1 目标

桌面 chrome 从「内联 hex 的 CoolDesktop 复刻皮」升级为「token 驱动的可换肤桌面层」，并把 fnOS 的档位思维（时长/阴影/圆角）落进 globals.css。

### 3.2 内容

1. **`--workbench-*` 变量族**（globals.css 新增段，`:root`/`.dark` 双值；不动 12 套 palette 的取值结构）：`--workbench-glass`（窗面 rgba 黑）、`--workbench-glass-border`（white 8%）、`--workbench-on-picture`（白字）、`--workbench-accent`（映射品牌 teal）、`--workbench-danger`、`--workbench-menu-*`（teal 菜单皮收编）、`--workbench-surface-1/2/3`（桌面内 elevation）。桌面组件（WorkbenchPane/Window/Taskbar/Starter/StatusBar/ContextMenu）内联 hex 全量替换为 var() 引用——**亮色桌面从此可能**（本批只验暗色不回归，亮色值留批次五接）。
2. **动效 token**：`--wb-dur-fast: 120ms / --wb-dur-base: 180ms / --wb-dur-slow: 220ms` + easing 两档（fnOS cubic-bezier(.4,0,.2,1) / (0,0,.2,1) 平移）；窗口开合/启动器/菜单统一挂 token；`prefers-reduced-motion` 保留。
3. **阴影三档**：`--wb-shadow-app/elevated/dropdown`（fnOS 配方：多层低透明 + 1px 描边），窗口/对话框/菜单各归其位。
4. **圆角档位**：窗口 12px、内容 8px（fnOS 16/12 的工具语境收敛版）；与 `--radius`/`[data-corner-style]` 派生体系兼容。
5. **图标文字双阴影**：`textShadow: 0 1px 6px rgba(0,0,0,.2), 0 0 4px rgba(0,0,0,.5)` 一行常量收编 fnOS 配方。
6. **基础件收编**：新建 `components/ui/WbButton.vue`（cva：primary/secondary/ghost × sm/md）与 `WbTag.vue`（三态浅底状态 tag：success/danger/warning-light），供批次二 Docker 页与后续窗口内容使用；431 裸按钮只收编桌面域与 Docker 域（全仓收编是 20261118-0801 计划的事，不在四期）。
7. **形态评审门（LESSONS I26）**：token 取值与圆角档先出预览 PNG（沿用 20261118-界面视觉预览 流程）交用户点头再落码。

### 3.3 车道与验收

- 车道：**视觉车道**（globals.css + 桌面六组件 + ui/WbButton/WbTag + spec）+ **主控**（评审门/门禁/回填）。
- 守卫风险：改动 WorkbenchWindow 头注与类名须过 selection/typography 守卫；桌面 spec 断言的内联色值改断言 CSS 变量。
- 验收：`pnpm check` 全绿；桌面六组件 `grep -n "#[0-9a-fA-F]\{6\}"` 归零（壁纸渐变除外，渐变也收进 token）；窗口/菜单/对话框阴影与时长视觉走查记录；无功能行为变化（31+21+8+7+5 spec 全绿即证）。

## 四、批次二：Docker 管理器 fnOS 化 ★重点

### 4.1 目标

ContainerPane 按 fnOS Docker 信息架构重排：左导航三页签（概览/容器/镜像）+ 状态 tag 化 + 概览摘要与迷你图 + 错误码人话映射。引擎零改动（24 条命令已够）。

### 4.2 内容

1. **左导航**：`WbSideNav`（220px 侧栏，fnOS SIDEBAR_WIDTH 度量）：概览/容器/镜像；引擎未连接或连接失败时只露概览（fnOS「服务未启用只露概览」的对应语义）；导航项带计数徽标（镜像总数，overflowCount 10）。**ContainerPane 按 §一第 7 条双模式隔离：`layout="desktop"`（桌面窗口内，左导航三页签）与 `layout="flat"`（应用级容器 tab，现状原样），应用级零 diff、既有断言不改。**
2. **概览页**：三行可点摘要（容器 共N/运行中N、镜像 共N、运行异常 N——hover fill-0、点击跳页签）+ CPU/内存/网络迷你折线（自绘 SVG，290×74 量级，**禁动画**，数据源 `container_stats` 既有流，5s 采样 + `visibilitychange` 停采）+ 健康灯文案。
3. **容器页**：状态列改 9 态映射（fnOS `status.container.*` 对齐 docker 状态字符串：running/exited/created/restarting/paused/dead/restarting(更新)→浅底 tag：success/grey/warning/danger）+ 行操作收进「更多」菜单（useContextMenu 复用）+ 删除确认带后果文案（「容器将被删除，容器中的所有数据将丢失」）。
4. **镜像页**：列表（tag/大小/创建时间/使用状态 tag）+ 拉取对话框（镜像名+标签，tag 正则校验提示）+ 删除/更新（pull 已有；「有新版本」判定用 registry history 既有命令比对 created 时间，可标 best-effort）。
5. **错误码映射**：`lib/backend/errorCodes.ts` 扩 Docker 域映射表（引擎 `ShellError` 码 → zh/en 人话），容器/镜像全部动作的错误呈现走映射；引擎新增错误码需同批补表（契约纪律）。
6. **loading 态文案枚举**：starting/stopping/restarting/creating/pulling/removing… zh/en 成对（i18n 守卫）。
7. **Compose/网络页：本批不做**。引擎无 compose/network 只读命令；若后续引擎增设 `network list`（只读）与 compose ls，则另立扩展批。

### 4.3 车道与验收

- **车道 H（Docker UI）**：`ContainerPane.vue` 重排 + `WbSideNav.vue`（新）+ `DockerOverview.vue`（新）+ `DockerImages.vue`（新）+ errorCodes 扩表 + i18n + spec（状态映射表驱动测试：9 态 × tag 色）。
- **主控**：WorkbenchDockerWindow 无需改（承载面不变）；真机只读验收；门禁回填。
- 验收：真机 Docker 窗口——概览三行数字与 `docker ps -a | wc -l` 一致；13 容器状态 tag 正确分类；镜像列表非空且计数徽标一致；容器「更多」菜单含启停/删除/终端/日志且删除确认有后果文案；stats 采样在窗口最小化时停止（`visibilitychange` 纪律）；错误注入（拔线/停 docker.sock 权限）呈现人话文案不裸码。

## 五、批次三：桌面形态升级

### 5.1 内容

1. **搜索式 Launchpad**：顶部 380px 搜索（300ms 防抖过滤应用+快捷方式）+ auto-fill 172px 网格 + scale 1.1→1 0.1s 进出场（fnOS KQe 度量平移）+ Esc 关闭保留；空搜索显示全部，输入即过滤。
2. **任务栏分段化**（保留横条形态）：三段「启动器 | 窗口列表 | 系统（时钟+电源）」，窗口格激活改 3px 左侧 accent 条 + white-10 底（替代红圆点）；新增「桌面」按钮（点击=全部最小化/再点恢复 toggle）；格子 hover 提示窗口标题（三期批次七项顺势完成）。
3. **窗口几何持久化**：`lib/workbench/windowMemory.ts`（新）——按 kind+sessionId 记 localStorage（防抖 100ms），openWindow 时恢复上次的尺寸位置（仍夹取进视口）；maximize 的 restore 矩形沿用现有机制。fnOS「按应用+用户持久化」对位。
4. **小部件四件套**：桌面右侧列（系统 uptime/网络收发/磁盘 IO/存储用量环），点击开 monitor 窗口；数据走 `monitor_sample`（2s 级采样，`visibilitychange` 与桌面失焦即停）；偏好进 localStorage（两种状态两个家纪律）；进度环 90/95 阈值变色。
5. **壁纸升级**：桌面设置对话框扩三分类——渐变（现有 4 款）/纯色（带不透明度滑杆）/自定义图片（本地文件 → 存 session vault 或 dataURL，尺寸预算与压缩策略实施时定）；fillMode（cover/contain）两态。动态双图层 crossfade 不做（素材依赖，立项另议）。
6. **窗口默认尺寸**：DEFAULT 666×422 → 900×600（向 fnOS 1100×640 靠拢但保 1366×768 下限余量），MIN 200×200 不变。

### 5.2 车道与验收

- **车道 I（桌面形态）**：WorkbenchStarter/Taskbar/Pane 改造 + windowMemory.ts + 小部件组件（`WbWidget.vue` 系）+ 壁纸设置扩展 + i18n + spec。
- **主控**：spec 修复/增补（31 例 WorkbenchPane 的壁纸/任务栏断言更新）；真机走查。
- 验收：搜索键入「doc」<300ms 出 Docker 瓦片；窗口关开恢复上次几何；小部件数字与 `uptime`/`df` 真机读数一致；桌面失焦 2s 内停止采样（DevTools network 佐证）；壁纸三类切换与会话保存回滚路径不破（既有 spec 平移）。

## 十、风险

1. **视觉回归面大**：桌面六组件 token 化触碰 ~190 个 spec 的断言——先改 spec 断言目标（CSS 变量而非色值），逐组件小步提交，任一组件 spec 全绿再进下一个。
2. **守卫测试**：selection/typography 守卫断言源码文本——新增 WbButton/WbTag/Empty 时先跑 `scripts/tests/` 确认无类名/字号冲突；WbTag 三态浅底若引入新字号须先修订 ui-conventions 类型节。
3. **Docker 真机只读**：启停/删除只对无状态测试容器（实施时 `docker run --rm` 造一个）或仅验证确认弹窗弹出即取消；禁止触碰 13 个用户容器。
4. **采样成本**：小部件 2s 采样 × 4 件套 + Docker stats 5s——全部挂 `visibilitychange`/失焦暂停，监控面板「没人看就不采样」纪律平移；真机读数 CPU 增量 <2%。
5. **壁纸资产**：自定义图片走 dataURL 可能撑爆 localStorage——实施时先测典型 1080p webp 体积，超限降采样压缩或改存 vault 文件（车道内决策，记录进实施小节）。
6. **长流背压**：tail/批量窗口沿用三期 §九契约的暂停纪律，验收时以「最小化 5s 内停止拉取」为判据。

## 十一、不做（四期主动裁剪）

- **改动/影响 Linux 桌面之外的任何既有功能**（§一第 7 条影响面锁死；共享组件只走双模式隔离）。
- Semi Design / recharts / mac-scrollbar 等库引入（自绘平替）；动态双图层壁纸（素材依赖）；Compose 与网络管理页（引擎无命令，扩展另立项）；多工作区/虚拟桌面；应用中心/自定义应用；磁盘分区/格式化（catastrophic 级单独立项）；NFS/SMB 挂载（零 footprint 冲突）；锁屏/多用户切换语义；40px 超圆弹窗；全局禁用右键；品牌换色。
