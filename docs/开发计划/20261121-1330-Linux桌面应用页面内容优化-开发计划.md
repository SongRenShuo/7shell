# Linux 桌面应用页面内容优化（图形化与打开即舒适）— 开发计划（立项）

> 2026-11-21 立项。用户口径：**「调研 Linux 桌面所有应用页面内的内容优化——例如很多内容都可以图形化显示，特别是监控；要让用户打开每个应用时布局都比较舒适」**。
> 调研依据：[Linux 桌面应用页面内容呈现——竞品与最佳实践调研](../调研报告/20261121-1330-Linux桌面应用页面内容呈现-竞品与最佳实践调研.md)（下称「调研」）。
> 边界：与 1050 计划（滚动条/选中态/浮层，已收口）正交——本计划不碰滚动条样式；与六期计划（功能可用性、编辑器）正交——本计划只动**呈现层**（图形、层级、三态），不改任何功能语义与 spec 断言的行为。
> 基线约束（沿用六期口径）：桌面红线不动——关窗即关连接、最小化不卸载、壁纸之上恒白字；无人观看不采样纪律不动；`--workbench-*` 只派生自 `--semi-*` 的单向箭头不动（`WorkbenchPane.spec.ts` 守卫）。

## 一、现状事实（2026-11-21 摸底，file:line 为证）

1. **监控窗口零图形**：桌面「监控」与「系统信息」两扇门开的是同一个窗口（`WorkbenchPane.vue:785-794`），窗体是 `SystemReport.vue`（249 行）——纯文字表格与 dl 列表：CPU 型号表、CPU 占比**一行数字**（:140-164）、内存/swap 四行数字、磁盘表。用户点名的「特别是监控」在代码上成立。
2. **数据底子够图形化，不用等后端**：monitor store 已有 60 点 ×2s 历史缓冲（traffic 按接口、roundTrips，`stores/monitor.ts:84/388/407`）；Docker 概览有 30 点 ×5s 三序列（`dockerMetrics.ts:12-15`）。**CPU/内存占用没有历史缓冲**——这是前端一改就能补的（照 traffic 的 push+slice 模式）。
3. **图形原语三种互不复用**：MonitorSpark（div 条，多序列共享峰值，`monitor/MonitorSpark.vue`）、StatSparkline（SVG 折线，逐序列自归一，`container/StatSparkline.vue`）、SystemPanel 磁盘环（inline SVG，`SystemPanel.vue:462-483`）。折线画离散采样与 MonitorSpark 注释里的裁决矛盾（调研 §速览 5）。
4. **阈值与色彩「有 token、无图形」**：`usageTone` 90/95（`lib/workbench/desktopWidgets.ts:56-63`）+ `--success/--warning/--destructive` 双主题（`globals.css:39-41/165-167`）；全仓消费阈值染色的图形只有磁盘环一处（且只有红档）。
5. **数字排版双轨失守**：widgets 用了 `tabular-nums`（`WorkbenchWidgets.vue:428`），其余数值页靠 `font-mono` 整体等宽（SystemReport 全部 `dd`、MonitorPanel 读数行），文字被连带等宽。
6. **打开即舒适现状**：窗口默认 900×600 居中（`lib/workbench/windows.ts:82-83`）；SystemReport 首屏是系统信息表（`space-y-5` 下滚）——首屏给的是「这台机器是什么」而非「现在怎么样」；SystemPanel 七分区默认落在 services 全量长表；widgets 四卡纯文字（宽 13rem 固定，`WorkbenchWidgets.vue:370`）。
7. **三态现状**：加载=39 文件 LoaderCircle 转圈（调研引 [现状盘点 §3.3]），骨架仅 7 处；空态=每页手写一行灰字或表格 emptyCell 行；错误态最规范（destructive 横幅+等宽码，Docker 窗带重试），但重试只有 Docker 窗有。
8. 图表库：`package.json` 无任何图表依赖（无 echarts/chart.js/uplot/d3）。

## 二、最高技术决策（先读这里）

| # | 决策 | 内容 |
|---|---|---|
| **D1** | **收敛共享图表词汇层，不引入图表库** | 新建 `components/charts/`：`StatTile`（大数字+阈值染+可选背景 sparkline）、`SparkBars`（离散采样条，吸收 MonitorSpark 的共享峰值语义）、`SparkArea`（趋势面积，吸收 StatSparkline 但**改条为面积**）、`RingGauge`（吸收 SystemPanel 环）、`MiniBar`（表格行内迷你容量条）、`SparklineStrip`（widgets 用细条）。全 SVG/div、无动画（实时数据纪律）、颜色一律 `var(--…)` token、无值画「—」不画零。**不新增依赖**：系列只有 30~60 点，canvas 库吃不了 oklch 色板且破坏令牌链路；uPlot 留给「历史长序列」立项再评估 |
| **D2** | **阈值一处、色三档** | 图形层的 ok/warn/crit 一律经 `usageTone(90/95)` 换算成 `--success/--warning/--destructive`（桌面 chrome 用 `--workbench-*` 同名档）；任何组件不得私设 80/85 等影子阈值。磁盘环补上 warn 档（现在 90 直接红） |
| **D3** | **数字排版双轨制** | 新工具类 `.nums`（`font-variant-numeric: tabular-nums`）进 `globals.css` 令牌层；**数值列/大数字/动态读数一律 `.nums`**，`font-mono` 退回给路径/命令/代码/错误码。单位永远随值（`%/s/MB`），裸数字视为缺陷 |
| **D4** | **监控窗口重构为「状态带 + 图形区」** | 首屏顶部一行 StatTile（CPU%、内存%、swap%、负载、在线时长，阈值染），其下图形区：CPU/内存 sparkline 条（吃 store 新增的 60 点缓冲）、网络速率条（复用既有 traffic）、磁盘组 MiniBar。CPU 占比「一行数字」改为水平条组。F-pattern：状态带在首屏左上，型号/内核等静态明细下滚 |
| **D5** | **每页一份「首屏契约」** | 打开即舒适按页裁定：默认尺寸沿用 900×600；每页规定第一屏必须完整出现的分区（监控=状态带+CPU/内存两图；系统面板=services 摘要+磁盘环；Docker=三行+健康灯+三图；widgets=全部启用卡无滚动）。第一屏之外允许滚动（1050 已把滚动条管好），但**不允许首屏内嵌套滚动区** |
| **D6** | **三态统一成样式与组件** | `globals.css` 补三态工具类：`.state-empty`（一句话+行动按钮位）、`.state-error`（沿用 destructive 横幅形态）；骨架 `.skeleton`（`animate-pulse` 灰块，镜像最终结构）只给结构可预测的整页（监控/系统面板首读）；单件等待保持转圈；<1s 的等待不画指示器。空态必须带行动入口（「去连接/去创建/重试」） |
| **D7** | **采样纪律是图形化的前提** | 所有新 sparkline 的数据源沿用「无人观看不采样」：桌面窗以 `active+visibility` 双闸（DockerOverview 模式，`DockerOverview.vue:120-140`），CPU/内存缓冲只在 pump 运行时增长；窗口不可见时图静止而非清零 |

### F. 密度与留白规范（全页通用，落 `globals.css` 令牌层）

- 间距节奏：卡片/分组内 `gap-2`（8px），分组间 `gap-5`/`space-y-5`（20px）——现有用法 majority 已如此，把两档写进约定并抽查合规。
- 图形最小可读字号：图形标签沿用 10px `uppercase+tracking` 既有词汇，**数字不小于 11px**；StatTile 主值 text-xl 级（唯一允许的大字号锚点，与 [现状盘点 §3.2]「缺大字锚点」互补）。

## 六、风险与边界

- **spec 文案耦合**：i18n 双语改动会碰 e2e getByText 与组件 spec 的 toContain——每页文案改动 en/zh 同批，spec 并批跑。
- **MonitorSpark/StatSparkline 是共享件**：替换波及 MonitorPanel（应用侧工作台）与 container 两域——词汇层先并行共存（旧件内部改为薄壳转发），全量切净后才删旧件，避免一次大爆炸 diff。
- **store 加历史缓冲的内存面**：60 点 ×2 数值可忽略，但缓冲增长必须挂 pump 闸（D7），否则后台窗口空转攒数据是采样纪律的破口。
- **桌面红线**：widgets 在壁纸上恒白字——SparklineStrip 的条色必须用 `--workbench-on-picture-*`/`--workbench-accent` 族，不能用主题语义色（深色主题下在浅壁纸上不可见的正是这些）。
- **不重复 1050**：滚动条、行选中、浮层 clamp 已收口，本计划任何页面改动不得回退那三项（验收走查时顺带核对）。
- **图表库诱惑**：中途若有人提议引入 echarts/chart.js——D1 已裁定不引入；推翻需走 docs/pips 流程并重估 CSP/令牌链路两个硬约束。
